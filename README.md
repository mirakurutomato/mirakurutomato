Computer-vision researcher working on **human pose estimation** and **motion analysis** for self-directed
learning support systems with real-time feedback — including sports-engineering applications such as Kyudo
(Japanese archery) form evaluation — and on **low-light image enhancement**, where I proposed the
Retinex-based methods **XCR** and **SD-Retinex**. I work end-to-end: from theoretical design to web
implementation and real-time processing.

低照度画像強調と姿勢推定を中心とした Computer Vision 分野の研究に取り組む高専生です。理論設計から
Web 実装・リアルタイム処理まで一貫した研究開発を行っています。
