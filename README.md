I work on **human pose estimation** and **motion analysis** for self-directed learning support systems with
real-time feedback — including sports-engineering applications such as Kyudo (Japanese archery) form
evaluation — and on **low-light image enhancement**, where I proposed the Retinex-based methods **XCR** and
**SD-Retinex**.

姿勢推定・動作解析・独習支援システム・リアルタイムフィードバック・スポーツ工学をキーワードに、
低照度画像強調 (XCR / SD-Retinex) を含む Computer Vision 分野の研究に取り組んでいます。
